# Primary journeys — Gemini v3

1. **Owner/broker/agency:** onboard organization (UI only) → create canonical property (existing fixtures and editable demo) → classify media → review bilingual copy and permit → prepare authorized connector → destination-specific preflight → human approval → async publish jobs (local demo only) → remote acknowledgment (NOT implemented).
2. **Lead and agent:** inbound partner/web/Meta/WhatsApp event (future signed adapter) → normalize/dedupe (not implemented) → route via round-robin/fallback (local preview) → conversation or viewing request (local preview) → qualified lead and attribution.
3. **Growth:** connect Meta / Google / GA4 only with approved permissions → draft campaign and review policy → sponsor approval and caps → provider execution (NOT implemented) → consent-aware event/lead reconciliation → channel ROI.
4. **Agency admin:** invite roles and verify licenses (UI only) → choose configurable entitlements (local plan preview) → manage business identity and white-label domains (DNS preview) → inspect connector health (local demo only).

See `13-design-acceptance.md` for screenshot/interaction acceptance; public marketplace is secondary showcase.
