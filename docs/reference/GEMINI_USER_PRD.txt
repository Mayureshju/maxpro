Product Requirements Document & Architecture Blueprint: Real Estate Operating System & Syndication HubExecutive Summary & Value PropositionIn markets like Qatar and the wider GCC, property owners, independent brokers, and real estate agencies face severe operational fragmentation. To market a single villa or apartment, they must manually enter listing details across multiple portals like Property Finder and Qatar Living, format product feeds for social channels, launch separate campaigns in Meta Real Estate Ads, and configure site tracking via Google Analytics 4.This platform acts as an All-in-One Real Estate Operating System (OS) & Connector Hub—effectively the "Shopify for Real Estate Brokers & Landlords." Users create a listing once, verify regulatory compliance, and click "Publish." The platform then automatically transforms, synchronizes, and syndicates that listing across external portals, ad platforms, tracking pipelines, and AI assistants according to their subscription tier.1. Portal Integration DynamicsProperty Finder: Real estate syndication is handled via the Property Finder Enterprise API and structured XML/JSON feed endpoints (e.g., standard PF XML schema). Listings require strict mandatory fields: property type, category (rent/sale), coordinates, price, payment frequency, completion status, and broker licensing (such as Qatar Ministry of Justice Real Estate Department permit numbers or UAE RERA/Trakheesi permits).Qatar Living: Listings run across residential and commercial sections (qlp.qatarliving.com). Integrations operate either via structured business XML/JSON automated ingestion feeds or headless webhook bridges that map agent accounts to property categories.Meta Real Estate Ads: Meta requires a dedicated Real Estate Catalog (part of Advantage+ Catalog Ads). Fields include home_listing_id, name, availability (for_sale or for_rent), price, address, neighborhood, latitude, longitude, num_beds, num_baths, property_type, and image. The feed updates automatically via a scheduled HTTPS XML/CSV feed or the Graph API.Google Analytics 4 (GA4): Event-driven tracking uses both client-side tagging and server-to-server (Measurement Protocol) tracking for high-intent actions (view_item, lead_submission, whatsapp_click, schedule_viewing).2. 4. Database Schema Outline (PostgreSQL)SQL-- Organizations / Brokerage Companies
CREATE TABLE organizations (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    name VARCHAR(255) NOT NULL,
    license_number VARCHAR(100), -- Qatar MoJ / RERA permit
    subscription_tier VARCHAR(50) DEFAULT 'starter', -- starter, pro, enterprise
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- Users (Owners, Brokers, Admins)
CREATE TABLE users (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    org_id UUID REFERENCES organizations(id) ON DELETE SET NULL,
    email VARCHAR(255) UNIQUE NOT NULL,
    phone_number VARCHAR(50) NOT NULL,
    role VARCHAR(50) NOT NULL, -- owner, broker, agency_admin, super_admin
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- Master Properties Table
CREATE TABLE properties (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    org_id UUID REFERENCES organizations(id) ON DELETE CASCADE,
    created_by UUID REFERENCES users(id),
    title_en VARCHAR(255) NOT NULL,
    title_ar VARCHAR(255),
    description_en TEXT,
    description_ar TEXT,
    property_type VARCHAR(50) NOT NULL, -- apartment, villa, commercial, etc.
    listing_purpose VARCHAR(50) NOT NULL, -- rent, sale
    price NUMERIC(14, 2) NOT NULL,
    currency VARCHAR(3) DEFAULT 'QAR',
    rental_period VARCHAR(20), -- monthly, yearly
    bedrooms INT,
    bathrooms INT,
    area_sqm NUMERIC(10, 2),
    location_city VARCHAR(100) NOT NULL, -- Doha, Lusail, Al Wakrah, etc.
    location_district VARCHAR(100),
    latitude DOUBLE PRECISION,
    longitude DOUBLE PRECISION,
    amenities JSONB DEFAULT '[]', -- ['swimming_pool', 'gym', 'balcony']
    images JSONB DEFAULT '[]', -- Array of image URLs with ordering
    permit_number VARCHAR(100),
    status VARCHAR(50) DEFAULT 'draft', -- draft, published, archived, rented, sold
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- Active Connector Configurations per Organization
CREATE TABLE organization_connectors (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    org_id UUID REFERENCES organizations(id) ON DELETE CASCADE,
    connector_type VARCHAR(50) NOT NULL, -- meta_ads, property_finder, qatar_living, ga4
    credentials_encrypted JSONB NOT NULL, -- API keys, client tokens, feed auth
    feed_token UUID DEFAULT gen_random_uuid(), -- Token for secure external feed pulling
    is_active BOOLEAN DEFAULT TRUE,
    last_synced_at TIMESTAMP WITH TIME ZONE,
    sync_status VARCHAR(50) DEFAULT 'idle' -- idle, syncing, failed
);

-- Syndication Publishing Log
CREATE TABLE listing_syndications (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    property_id UUID REFERENCES properties(id) ON DELETE CASCADE,
    connector_type VARCHAR(50) NOT NULL,
    external_listing_id VARCHAR(255),
    syndication_status VARCHAR(50) NOT NULL, -- active, pending, error
    error_message TEXT,
    last_syndicated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

Agile Implementation Roadmap (Fast-Track 12-Week MVP)[ Weeks 1 - 2: Architecture & Foundation ]
  ├── PostgreSQL database setup & multi-tenant schema definition
  ├── Auth0 / Supabase RBAC implementation (Owner vs. Broker vs. Agency)
  └── Master Property Management CRUD UI (Next.js 14 + Shadcn UI)

[ Weeks 3 - 5: Feed Generation & Static Connectors ]
  ├── Cloudflare R2 / AWS S3 image upload and optimization pipeline
  ├── Meta Real Estate Catalog XML generation engine
  ├── Universal Feed Endpoint architecture (Unique tokenized feeds per tenant)
  └── Google Analytics 4 tracking integration

[ Weeks 6 - 8: Portal Syndication & AI Engine ]
  ├── Property Finder XML/JSON schema transformer
  ├── Pre-flight validation rules engine (validating portal constraints)
  ├── BullMQ background workers for async feed dispatching
  └── OpenAI bilingual Arabic/English copywriter generator integration

[ Weeks 9 - 10: Lead Management & WhatsApp Integration ]
  ├── Hosted white-label listing landing pages (`domain.com/p/listing-slug`)
  ├── Meta Lead Ads webhook capture
  └── WhatsApp Cloud API automated notification dispatch to brokers

[ Weeks 11 - 12: Billing, Testing & Launch ]
  ├── Stripe / Regional GCC Payment Gateway integration
  ├── Subscription gating & quota enforcement middleware
  └── Beta onboarding with 2–3 pilot real estate brokerages
Verification and Next StepsPilot Portal Credentials: Verify whether your brokerage partners possess active Property Finder Enterprise API accounts or prefer the standard XML pull feed integration, as API access requires partner verification.Local Payment Gateway Selection: For Qatar and the GCC, evaluate whether you want to implement Stripe alongside local providers like SkipCash or Tap Payments to support Qatar Debit Cards (NAPS) in addition to credit cards.
