# Design system for prototype v2

This document points to the approved working design direction: **`docs/09-design-direction.md`**. The original starter v1's gradient-heavy teal system has been retired for this prototype. The current brand is provisional until MaxPro/AqarPro identity is approved.

- UI tokens live in `apps/web/src/app/globals.css` under `MAXPRO PROTOTYPE V2 · ATELIER SYSTEM`.
- Primary ink `#1B292D`, dark `#203B37`, interaction eucalyptus `#255D52`, copper `#AA774D`, warm canvas `#F6F6F2`.
- App shell and public site share core colors but have distinct layout grammar.
- Inputs and controls are mostly squared, panels are bordered rather than shadowed, photography is used for the public real estate experience.
- Production component extraction is an explicit Codex hardening task, not something to falsely mark as already completed.
- English/Arabic route prefix and root `dir` exist; complete Arabic label translation remains open.
