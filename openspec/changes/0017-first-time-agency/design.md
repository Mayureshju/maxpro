# Design

Retain the six-item shell and shared editorial/operational controls. Add a dismissible inline dashboard guide, scoped by organization in a separate UI preference (never authorization). Derive completion from the same property's saved content/review/preparation/outcomes; do not persist synthetic completion flags. Seeded established workspaces keep the daily dashboard.

Quick Add captures a small initial fact set using the existing guarded create command. Preserve empty/full editor entry, incomplete drafts, revisions and organization context. Save/Continue persists the active step in the URL; offer direct review from details, keeping assistance available inline. Offer field-specific validation and source-based warnings without requiring AI.

Portal preparation offers a repair link and truthful status. After a current locally queued portal job, explicitly request a fictional enquiry using existing exampleLeadPayload and crmCommand intake. Stable organization/property/source event identity plus existing deduplication prevent duplicate leads/assignment/analytics. Reopen existing examples without new intake. Fresh agency owners start unavailable; an explicit example-only action makes the same-organization active owner available and assigns the enquiry through existing permission-checked CRM commands. No enqueue or click implies remote acceptance.

Assistance keeps original sources, editable comparisons, explicit accept/dismiss and stale-source protection. Add warnings for missing source facts. No invented factual defaults, credentials, personal data or remote side effects.
