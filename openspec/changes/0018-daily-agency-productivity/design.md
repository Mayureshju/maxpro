# Design

Use saved-record selectors and existing shared controls. A complete coherent property journey takes precedence over older unfinished drafts. Completion is compact, with steps disclosed; dismissal remains organization-specific.

Dashboard presents attention, recorded scheduled work, a compact portfolio line and linked readable activity. Audit labels are centralized; optional validated CRM event context snapshots record actual alias/source/assignment at mutation time. Old events without context use generic labels. Links resolve only current scoped records. Never render raw action/note syntax as activity text.

Quick Add has Save & continue (valid essentials → editor) and Save as draft (partial essentials → property workspace). A blank form can start the full editor. No duplicate record, whitespace-only required values, invalid numeric carryover or silent permission failure.

Inventory keeps search/filter/list/grid behavior, replaces sample-view ranking with title sorting, and promotes updated time and primary next action over revisions. Mobile rows expose meaningful facts without requiring horizontal scanning. Revision detail stays contextual.

Publish URL remembers property, goal, selected channels and active channel; these are navigation preferences, never saved content/approval. Saved jobs/campaigns/sharing provide separate recovery links and statuses. Changing organizations remounts local form/filter state through the existing permission surface.

CRM uses recorded last-message direction for unanswered state, no response deadlines. Existing contextual assistance, stale-source checks and engines remain authoritative.
