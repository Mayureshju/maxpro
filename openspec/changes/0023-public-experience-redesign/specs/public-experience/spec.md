# Public experience specification

## Agency owner scan (GEM-01/02/13/21)
Given a first visit, the hero names properties, marketing and enquiries and exposes demo plus how-it-works. The primary image is an actual property detail, not a full editor form. Four story chapters make the listing-to-enquiry progression understandable with short outcomes.

## Accessible product story (GEM-03/22)
Given EN/AR desktop/mobile, four explicit controls select exactly one associated panel. Arrow navigation, Home/End, focus and aria-selected reflect selection. RTL direction is honored. Essential content never auto-rotates. Enlargement opens the selected authentic locale/native-mobile image. Reduced motion removes nonessential transitions. Six widths 320/375/768/1024/1280/1440 and 200% CSS zoom have no document overflow.

## AI review (GEM-21)
Given source notes, use the existing deterministic parser, explain its explicit-label limitation, show proposed fields and require explicit acceptance. Accept/reset changes page memory only. No public private agency access, localStorage write or API mutation. No live model claim. Dedicated AI page explains bilingual draft/CRM assistance and production prerequisites.

## Channel and CRM truth (GEM-05/08/10/11/13/14/15/16/24)
Group portals, paid ads and direct sharing by purpose; explain official access, consent and separate approvals. Google Business Profile stays planned/eligibility unverified. Approved, queued locally and remotely accepted remain separate; no remote acceptance without acknowledgement. CRM evidence shows genuine fictional property-linked enquiry and human responsibility; no delivery, availability or revenue promises.

## Buyer route family (GEM-01/03/18/19/22)
All public routes retain one h1, unique localized metadata/canonical/hreflang, useful links and real RTL. Pricing remains QAR 179/725/1800+; 3/25/negotiated listings; 1/2/all authorized portals; illustrative pending approval. Contact remains fictional preview. Entry keeps existing commands/errors/hydration, explicitly fictional information. Showcase remains secondary and navigable.

## Non-UI acceptance
No canonical engine/schema or dependency changes without a concrete defect. No backend or provider connections. Frozen install, typecheck, lint, default build (document sandbox fallback if needed), full Playwright, EN/AR responsive screenshots visually inspected, axe including expanded controls, browser performance and independent review. Record actual command results and limitations. No commit/push/deploy.
