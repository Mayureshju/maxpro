# Proposal — complete UX prototype, not a landing-page starter

**Why:** v1 shipped only a homepage, pricing and four workspace modules. The product reference and earlier requirements include complete advertiser workflows, agents, payments and admin. The v1 UI felt repetitive and lacked distinctive real-estate language.

**What:** build a broad navigable Next.js demonstration with route mapping, the Atelier visual system, workflow-specific layouts, six-stage Listing Studio and local interactive demos. Record unsupported real integrations and gaps explicitly.

**Out of scope for THIS change:** production API, authentication, persistence, real payments, AI calls, live portal publication, WhatsApp/Meta connections. No hidden stubs should be presented as operational.

**Risk:** The Gemini reference cannot be read and the earlier MaxPro website brief differs from the live AqarPro portal-publishing strategy. Product owner must reconcile before final scope signoff.
