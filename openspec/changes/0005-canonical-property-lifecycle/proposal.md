# Canonical property lifecycle

Agency operators need one record from creation through source review, media, bilingual copy, validation and local publishing history. Today inventory/details use static fixtures, the editor stores separate overrides, Studio invents fixed extraction values without saving, media resets on navigation, and preflight counts fixture media rather than managed assets.

Implement a typed, versioned, browser-local property repository inside the existing demo provider. Seed existing examples and migrate valid Phase 0 edits. Connect the existing task-specific screens; preserve the optional public showcase and unrelated operations.

Scope: GEM-02 (CRUD/revisions), GEM-03 (bilingual/RTL), GEM-04 (ordered room media), GEM-05 (canonical preflight), GEM-08 (destination attempt history), GEM-18 (illustrative quotas), GEM-21 (source/proposal/human review). No backend, AI calls, real integrations, credentials, commits, pushes or deployment.

Author: Codex. Independent second-tool review remains pending; it must review this same change rather than introduce scope. Automated checks and an explicit implementation self-review provide evidence but do not substitute for that review.
