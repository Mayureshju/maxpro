# Design

Add campaignSchemaVersion 1 and a typed campaign repository to the existing browser-local envelope. Older envelopes migrate to an empty portfolio. Validate bounded known fields, enums, finite amounts, dates, ownership, property/media references, revision-bound approval ordering and histories. Exclude corrupt campaign records while retaining valid properties, jobs and CRM; unknown IDs show an explicit unavailable state.

Campaigns store property identity/revision, objectives, proposed Meta/Google channel, bilingual editable copy, media IDs, dates, media budget, separately specified service fee, broad or unsupported targeting, local review checklist, approval receipts, status and append-only activity. Do not snapshot canonical facts or creative binaries. Property changes invalidate dependent reviews and approvals atomically in the shared store; persistence recovery reconciles stale references. Relevant edits increment revision and clear approvals. Duplicate gets new identity and starts draft; cancel/reject/resume preserve history.

Commands require expected revision, organization and a known demo role (editor/policy reviewer/advertiser/admin). The explicit local role selector demonstrates guards, not production authentication. Policy reviews check current verified sample facts, license/owner flags, bilingual content, available selected media, human content/rights/category review, unsupported targeting, numeric dates/budgets and illustrative plan entitlements. Unverified provider/legal rules remain pending outside the local review. A checkbox cannot approve or simulate; only ordered commands can issue revision-bound receipts. Simulation revalidates prerequisites, entitlements and local setup, never creates remote status or external IDs.

A provider-agnostic AI proposal contract returns deterministic suggestions from reviewed canonical fields, source paths and revision. Content, headlines, feature emphasis, objective, creative and budget scenarios remain editable proposals with accept/reject history. No extraction, model, inferred facts or invented performance. Weekly drafts use only dated campaign-linked CRM observations when present.

Campaign enquiry commands call existing CRM intake with stable fictional source event IDs and campaign references. Replays preserve deduplication, first-touch and routing behavior. Google examples use Website first touch with Google campaign reference because Phase 3 has no Google intake contract; disclose this mapping. Campaign metrics reuse leadMetrics/selectLeads. Explicit dated campaign cost examples are also recorded in existing source spend, without inferring spend from budgets. Property-filtered source CPQL must not divide unscoped costs by a property subset.

Task layouts: filterable portfolio table, guided editor + contextual fact inspector, creative metadata gallery, structured policy checks, ordered approval actions/audit timeline and transparent analytics tables with local lead-stage bars. EN/AR labels and RTL/logical CSS; primary flows support 1440/1024/768/375 pixels, focus, errors, empty/loading and recovery states. Professional Arabic/legal/provider review remains outstanding.
