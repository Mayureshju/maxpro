# Design and boundaries

Keep warm stone, eucalyptus, existing px/gm primitives and canonical demo engines. Introduce scoped shared tokens, 248/72px desktop navigation and a single 64px sticky header. Tablet/mobile use a modal navigation drawer; local preferences are separate from organization records. Breadcrumbs resolve canonical property/lead/campaign context.

The four-step wizard has optional contextual assistance from step one, explicit draft saves, revision checks and a reserved action dock. Completeness counts named content checks independently of human review; each destination retains its own engine readiness/setup/quota checks. Property detail prioritizes operations and compact disclosure.

Promotion reveals one goal and its channels, then a focused provider preparation view with separate history. Portals, paid campaigns and direct preparation preserve existing guarded commands and distinct outcomes. Assistance is a reusable modal inspector: labelled deterministic examples, source records, editable before/after proposals, explicit acceptance/dismissal and source fingerprint invalidation. No silent overwrites or inferred approvals.

Authoring is confined to this change. Review tooling checks the authored spec through type/lint/build, domain regressions, browser acceptance and actual screenshot inspection; independent external-tool review remains a handoff prerequisite if unavailable in this session.
