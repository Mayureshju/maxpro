# Product experience acceptance

## GEM-21/01/03/22 — assistance
Given a workspace question and unsent input, when the user minimizes and follows an internal navigation link, then reopening retains the question/answer/source snapshot and input. Current property/lead context follows the new route. Switching organization or persona clears all history/input/proposals and restores scrolling, including cross-tab changes. Public mode only reads public FAQ/plans/statuses and never shows saved agency records. No assistant request mutates jobs, campaigns, messages, approvals, quotas or spend. Only the existing explicit proposal inspector can save property copy, with current revision and authorization guards.

Native dialog contains focus, returns it on close, supports Escape and nested inspectors. Launcher is fixed at logical inline-end, unobstructed by mobile editor controls, never auto-opens, and is absent from the header. Test EN/AR desktop/mobile, 320/375/768/1024/1280/1440, reduced motion and 200% zoom.

## GEM-02/05/08/13/14/16/24 — daily journeys
Populated dashboards show attention/enquiries before expandable setup help. Empty agencies keep record-derived first-use progress and no repeated zero panels. Inventory search/title/ID/location, visible purpose/state filters, sorting/list/grid, no-results recovery and per-property next actions remain functional for 25+ fictional records. Property navigation reaches content/media/readiness/publishing/campaigns/leads/activity through existing routes. Publishing repair keeps selected destination context. Existing revision conflicts, stale approvals, quota, consent/STOP, assignment and archived/unknown recovery tests remain authoritative.

## GEM-03/06/18/19/21 — public product explanation
Homepage exposes AI and five-stage property→AI→review→channels→enquiries journey using actual rendered screenshots and keyboard-operable steps. Explain six bounded AI outcomes and owner/broker/agency needs. Existing AI/platform/walkthrough/integrations/pricing/agency/contact/FAQ/showcase routes and metadata persist. Provider statuses and QAR 179/725/1,800+ pending-approval examples remain accurate. No unsupported security claims.

## Non-UI
No domain engine replacement, duplicate record authority, new dependency or backend framework. Session is in memory; no prompts, secrets or personal data added to browser storage. Full existing regressions plus new journeys, production build and actual screenshot/accessibility evidence required. Document professional Arabic, physical-device and production prerequisites without claiming they passed.
