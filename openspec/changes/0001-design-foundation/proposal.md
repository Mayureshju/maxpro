# Proposal: Bilingual UI and design foundation

## Intent
Deliver a coherent, high-quality Next.js design foundation for the current AqarPro agency-first product, while retaining provisional MaxPro branding until D-07 is signed off. Prevent fragmented page-by-page styling and tool-specific instruction drift.

## Scope
- Semantic design tokens, English/Arabic localization, RTL support.
- Public landing + pricing; demo workspace overview, AI Studio, Portal Hub, Leads.
- Shared navigation patterns, responsive foundations, accessibility and honest demo states.
- Tool-portable AGENTS instructions and documented design review gate.

## Out of scope
- Real identity, database, billing, portal publishing, WhatsApp, AI or Meta APIs.
- Source-of-truth resolution beyond documenting the AqarPro/MaxPro conflict.
- Full public property search/listing page implementation.

## Risk and mitigation
Existing prototype may already contain reusable UI components. Request source audit before merging; avoid rewriting working code without inspecting it. Brand assets/design approval pending. All sample data labeled as demonstrative.
