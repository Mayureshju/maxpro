# Design

Restore explicit React hook/type imports in the existing Gemini client components. Keep shared demo state browser-local and safe when storage is absent or malformed. Use React's external-store hydration contract for persisted state; initialize editor form state from the hydrated record without effect-driven state resets. Fix only defects demonstrated by checks/browser evidence, using existing tokens and logical RTL CSS.

Verification uses the installed dependency set and Playwright against the actual Next.js app, including EN/AR, desktop and mobile, page/console errors, navigation, preflight, setup, quotas and local job history. Screenshots are browser captures. No provider calls, payment, AI or publishing acceptance is inferred.
