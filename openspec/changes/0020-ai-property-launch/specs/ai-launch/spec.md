## GEM-02/03/21 — grounded assistance

Bilingual proposals display the source ID/revision, actual facts, missing-source warnings and editable before/after values. Dismiss causes no mutation. Explicit acceptance uses optimistic saveProperty and does not approve facts, copy, moderation, publication or spending. Source/organization changes prevent stale acceptance.

## GEM-01/13/14/16/21 — global Copilot

Empty/no-property and unsupported requests have useful fallbacks. Context follows property, campaign, lead and publish routes. Requests naming another property must not mutate the selected property. No model or provider request occurs. Escape restores focus; mobile and RTL fit 320–1440px. Local role checks remain UX simulation.

Unavailable extraction and GBP capabilities are explicitly future integrations.
