# Design

Add organization schema v1 to the existing envelope. Typed OrganizationRepository owns profiles, memberships, selected fictional persona, plan overrides, moderation decisions, settings, invoice examples and bounded audit events. Directory organizations are fictional onboarding records; existing Phase 1–4 operations remain in the explicitly identified Pearl Gate workspace. Do not imply dataset switching or production tenant isolation. Commands validate permissions, record revisions, canonical references and quotas. Member changes synchronize assignment availability without renaming historical assignees. Reserved invitations consume seats; only active members can route leads. Retain a last active owner. Every restricted workflow uses the same matrix as command guards. Default super-admin preserves existing demo journeys; persona selection is explicitly a simulation.

Plan selection previews blockers and permits an over-limit local selection for existing Phase 1–4 compatibility, but blocks new seat reservations/connector preparation/publishing/AI suggestions until usage is resolved. Illustrative pending-approval prices remain configurable from gemini-product defaults; drafts do not consume listing quota. Source review, administrative approval and partner acceptance are separate. Review actions bind canonical revision; every property revision returns dependent reviews to verification-pending and invalidates campaign approvals in the same update. Previously queued jobs show stale revision and never become remotely accepted.

Async typed data-access facade describes snapshot/query/command results and future Frappe errors, optimistic revisions and idempotency metadata; only local adapter implemented. Production must derive actor/organization from authenticated Frappe session, enforce permissions in controllers and whitelisted methods, and transact quotas, audit and job reservations.

Task-native profile forms, team and organization tables, subscription comparison/usage, review inspector and audit table use existing px/gm tokens. EN/AR labels, RTL/logical CSS, keyboard, mobile layouts, loading, empty, validation, denied, success and storage recovery states. Professional Arabic review remains pending.
