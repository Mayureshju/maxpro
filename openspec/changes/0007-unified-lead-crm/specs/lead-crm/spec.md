# Acceptance contract

- GEM-13: each of five illustrative contracts normalizes into an organization-scoped lead linked to any existing canonical property, including newly created ones. The canonical property Enquiries tab lists shared leads and opens intake with that property preselected. Original source/event/time survive reload. Unknown property/foreign tenant/malformed JSON or fields reject explicitly without altering saved leads. Received and terminal receipts append. Replay yields duplicate, same lead and no assignment/cursor change. Same-name different event remains distinct.
- GEM-14: available active agents rotate deterministically, cursor survives reload, inactive/unavailable agents excluded; manual selection/reassignment validates agent; fallback and empty eligibility produce traceable decisions/backlog. Rules and histories persist.
- GEM-13: search and source/property/owner/stage/priority/qualification filters, table/pipeline, detail and notes operate on one repository. Six stage transitions persist and update reports. Unknown lead never renders another person. No real personal details collected.
- GEM-16 bounded: linked channel conversation, local reply, opt-out guard and agent handover persist. Never send network messages or claim remote delivery.
- GEM-15 bounded: requested local date/time, lead/property/agent and permitted status changes persist. Local/example conflicts warn; cancellation releases slot. No live calendar or invitations.
- GEM-24: shared filtered lead totals, new/qualified/won/backlog, conversion, valid response samples and property counts update after intake/assignment/stage changes. First-touch attribution preserved. Explicit dated fictional spend only; unavailable costs/views/revenue clearly marked.
- Browser acceptance: new event, replay, invalid event, round-robin/reload, stages/reporting, linked replies, viewing/cancel/conflict, attribution, new property, corrupt recovery, EN/AR desktop/mobile, keyboard, widths 1440/1024/768/375, existing publishing/feed regression. Real screenshots of table/pipeline/detail/inbox/rules/viewings/analytics/control tower.
- Non-UI: frozen install, baseline CI status and tests, typecheck/lint/default build (report failures), supported webpack alternative if restricted, full regression suite. Record exact results and remaining review/Arabic/production prerequisites in docs/19-phase3-lead-crm.md; update requirements matrix.
